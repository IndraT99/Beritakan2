## 2024-07-26 - Add ARIA labels and fix duplicate focus stops in navigation toggles
**Learning:** When adding ARIA labels to icon-only buttons that contain a nested standalone `<a>` link (e.g., `<button><a href="..."><i class="..."></i></a></button>`), the inner `<a>` needs `aria-hidden="true"` and `tabindex="-1"` to prevent duplicate and empty focus stops for screen readers, while the ARIA label belongs directly on the `<button>` parent. For standalone icon-only links without a parent `<button>` (e.g., `<a href="..."><i class="..."></i></a>`), the ARIA label should be applied directly to the `<a>` tag itself without hiding it.
**Action:** Always check the parent-child structure of interactive elements. Ensure redundant inner interactive tags are hidden from screen readers and removed from the tab sequence if the parent already handles interaction and holds the accessible name.
