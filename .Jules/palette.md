## 2024-05-18 - Invalid Nested Tags and ID Collisions on Icon Toggles
**Learning:** Found a recurring anti-pattern where an `<a>` tag was nested inside a `<button>` tag for icon-only dropdown toggles. This invalid HTML structure creates duplicate focus stops and can confuse screen readers. Also found that `id="dropdownMenuButton1"` was being copy-pasted across multiple distinct toggle instances causing HTML invalidity and ID collisions that could lead to JavaScript event issues.
**Action:** When inspecting navigation headers or menus, proactively look for nested interactive elements and duplicate `dropdownMenuButton` IDs. Ensure that standalone toggles use valid semantic tags with appropriate `aria-label`s instead of nesting `<a>` inside `<button>`. Assign unique, descriptive IDs to dropdown targets (e.g., `dropdownMenuButtonMobileSearch`).
