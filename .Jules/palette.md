## 2024-05-24 - Missing ARIA Labels for Icon Buttons\n**Learning:** The application extensively uses standalone `<a href="javascript:void(0)">` or `<a href="#">` tags with nested `<i>` icons (like search or expand actions) without any `aria-label`, rendering them completely inaccessible to screen readers.\n**Action:** Add descriptive `aria-label` attributes to these `<a>` tags, utilizing existing translation keys (e.g., `__('messages.search')`) when possible.
