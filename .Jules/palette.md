## 2024-08-23 - Accessibility Issues in Navigation Header Dropdowns and Menus
**Learning:** Duplicate HTML IDs (e.g., `dropdownMenuButton1`) were widely used across distinct search and user dropdowns in the layout header, which breaks uniqueness requirements and can confuse assistive technologies linking elements via `aria-labelledby`. Additionally, icon-only toggle buttons frequently used a redundant nested `<a>` tag inside a `<button>` (e.g., `<button><a href="javascript:void(0)"><i class="icon"></i></a></button>`), which creates duplicate focus stops and lacks descriptive `aria-label`s.
**Action:** Always ensure HTML IDs are unique when copying/pasting components like Bootstrap dropdowns. For icon-only interactive elements, apply the semantic structure (either a `<button>` or an `<a>`), apply an explicit translation-based `aria-label` (e.g., `aria-label="{{ __('messages.search') }}"`), and remove redundant nested interactive tags to ensure a single, clear focus stop for screen reader users.
