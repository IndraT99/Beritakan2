## 2026-06-23 - Added ARIA labels to header icon-only toggle buttons\n**Learning:** When making icon-only toggles using a button containing an anchor tag, adding `aria-hidden="true"` and `tabindex="-1"` to the anchor prevents empty/duplicate focus stops for screen readers, while applying the `aria-label` directly to the wrapping `<button>` properly announces the element.\n**Action:** Always check the element hierarchy inside icon-only buttons to ensure nested links or icons don't create extra noise for screen readers, and consider using proper `aria-label`s sourced from translation files (e.g., `__('messages.search')`).
