## 2024-05-24 - Accessibility for Icon-Only Buttons in Headers
**Learning:** Found multiple instances where header navigation uses `<a href="javascript:void(0)" class="btn...">` for icon-only action buttons (Search, Fullscreen, Dark/Light Mode) across several Blade views (e.g., `layouts/header.blade.php`, `front_new/layouts/header.blade.php`). Although some have tooltips via `title`, they lack the standard `aria-label` attribute required for screen reader accessibility. Adding `aria-label` to these links improves the usability for users relying on assistive technologies to navigate.
**Action:** When working on navigation components that render custom row cells with icon-only links/buttons, always ensure `aria-label` attributes are included, preferably using the existing localized string used for tooltips or titles.
