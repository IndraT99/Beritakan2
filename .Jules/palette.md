## 2024-05-24 - Duplicate Dropdown IDs and Nested Links in Header
**Learning:** The application's header layout contained multiple dropdown toggles all using the same ID (`dropdownMenuButton1`), which breaks accessibility and HTML validity. Additionally, icon-only dropdown buttons had redundant `<a href="javascript:void(0)">` tags nested inside them, causing duplicate focus stops and missing `aria-label`s.
**Action:** Ensure all dropdown toggles have unique IDs. When fixing accessibility for icon-only toggles in Blade templates where an `<a>` tag is nested inside a `<button>`, completely remove the redundant `<a>` tag leaving the icon (e.g., `<i>`) directly inside the `<button>` to prevent duplicate focus stops, and ensure the parent `<button>` has an appropriate `aria-label`.
