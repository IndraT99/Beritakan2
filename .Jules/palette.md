## 2024-05-24 - Accessibility improvements for icon-only buttons
**Learning:** Found several standalone links that only contain icons and use `<a href="javascript:void(0)"><i class="fa-solid fa-magnifying-glass"></i></a>` nested inside `<button>` or as direct toggles. These links lack proper ARIA labels and duplicate focus states if inside a `<button>`. Memory specifically instructs not to use aria-hidden="true" on standalone interactive links, but does instruct to use aria-hidden="true" and tabindex="-1" when an `<a>` is nested inside a `<button>`.
**Action:** Adding `aria-label` to the outer `<button>` or `<a>` elements for accessibility. And specifically, for icon-only toggles in Blade templates where an `<a>` tag is nested inside a `<button>`, applying `aria-hidden="true"` and `tabindex="-1"` to the inner `<a>` to prevent duplicate or empty focus stops for screen readers. Using translation files where possible, e.g., `{{ __('messages.search') }}`.
